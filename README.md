# FED assignment - Singapore Hawker Centre Management System

## Description
This project is a web application developed for the Front End Development module assignment.
The website allows users such as customers to place and checkout orders, stall vendors to manage their stalls, NEA officers to inspect and grade stalls, and operators to see the hawker centre overview.

## Features

**Customers**
- View available stalls and food items
- Place orders on multiple items
- Change cart item quantities
- Checkout orders
- Give likes to items
- Give feedback to stalls

**Stall vendors**
- View stall overview
- Manage their menus
- Create and edit menu items
- Manage stall promotions
- Manage their queues

**NEA Officers**
- Conduct stall inspections
- View inspection records

**Operators**
- View overview of hygiene ratings, complaints, and stall performance

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Flexbox
- Firebase Realtime Database
- Firebase authentication

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser or Live Server in VS Code

## Limitations
- This project is designed for desktop screens and may not be fully optimized for mobile devices.
